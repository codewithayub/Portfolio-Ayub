# Ayub Portfolio Website

A modern and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

* Responsive Design
* Modern UI
* Smooth Scrolling Navigation
* Hero Section with Profile Image
* About Section
* Projects Showcase
* Contact Form
* Back to Top Button
* Mobile Friendly Layout

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio-website.git
```

2. Open the project folder.

3. Add your profile image and rename it to:

```text
profile.jpg
```

4. Open `index.html` in your browser.

## Customization

* Update your name in `index.html`
* Replace project details
* Add your social media links
* Change colors in `style.css`
* Connect EmailJS for email functionality

## Deployment

This website can be deployed on:

* GitHub Pages
* Netlify
* Vercel
* Any web hosting service
